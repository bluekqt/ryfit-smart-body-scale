# 云悦(RyFit) 智能体质分析仪

> **脱离官方 App，独立使用的体脂秤桌面应用**  
> 通过逆向工程完整破解 云悦(RyFit) 智能体质分析仪的私有蓝牙协议，实现多用户管理、实时数据采集、历史同步和健康分析报告。  
> 重构采用前后端分离架构，蓝牙子系统模块化，引入测量状态机、WebSocket 双向直连，界面采用流体排版自适应所有分辨率。

---

## 🚀 功能特色

- 📡 **蓝牙自动连接与休眠唤醒**：自动连接设备，断线重连、心跳维持，空闲 10 分钟自动休眠，一键唤醒
- 👨‍👩‍👧‍👦 **多用户管理**：
  - **家庭成员**：绑定秤上用户编号（P1-P8），数据永久保存在秤内，可离线自动识别
  - **本地用户**：不占用秤内编号，数据仅保存在本地，可随时升级为家庭成员
  - **游客称重**：一次性快速测量，不保存任何记录
- ⚖️ **智能槽位管理**：自动查询秤上已占用编号，注册时可选择空闲编号；支持本地用户一键升级至固定槽位
- 🔄 **同体重冲突解决**：称重前自动发送当前用户配置，避免多人同体重时秤无法区分
- 🔁 **历史数据同步**：蓝牙就绪后避开测量期，自动同步秤内所有已注册编号的历史记录，并智能绑定或创建本地固定用户
- 🧠 **自动匹配与跳转**：秤上独立测量时，App 自动识别已注册用户编号，并跳转到对应用户的测量页面
- 📊 **完整测量数据**：体重、BMI、体脂率、肌肉量、骨量、水分、基础代谢、皮下脂肪、内脏脂肪、身体年龄
- 📈 **可视化分析报告**：彩色进度条显示各项指标水平，星级评分，基于中国国民体质监测数据的体脂排名
- 📜 **历史记录**：测量数据存储于 SQLite 数据库，支持按用户查看、多选删除、点击历史行查看详细分析
- 🔧 **数据管理**：齿轮菜单提供【导出 CSV】【导入 CSV 到指定用户或本地】【重置所有数据】等操作
- ⚙️ **用户编辑**：铅笔图标可修改用户信息（姓名/身高/年龄/性别），支持本地用户升级为固定用户、固定用户降级为本地用户
- 🔐 **开发者面板**：通过 Shift + 点击标题打开，支持写入设备码等高级功能
- 🛡️ **稳定可靠的测量流程**：自动补发 C0 解决休眠后无法测量；测量超时、失败时弹出独立对话框引导重试；称重进度清晰，大字体重 + 小字提示，报告展示时“再次测量”按钮自然出现
- 🖥️ **Electron 桌面窗口**：打包成独立安装程序，双击即用，无需 Python 环境
- 🎨 **全分辨率自适应**：采用 Fluid Typography 流体排版，手机、平板、桌面、Electron 窗口均自动适配

## 📋 快速开始

### 1️⃣ 安装依赖
```bash
pip install -r requirements.txt
```

### 2️⃣ 配置设备地址
复制 `config.example.py` 为 `config.py`，并修改其中的蓝牙设备地址（MAC）：
```python
BLE_DEVICE_ADDRESS = "D0:39:72:XX:XX:XX"   # 替换为你的秤的 MAC 地址
```

### 3️⃣ 启动后端
```bash
python app.py
```

### 4️⃣ 打开浏览器
访问 `http://127.0.0.1:5000`

### 5️⃣ 使用流程
- **注册家庭成员**：点击“＋ 注册”，填写信息，选择“家庭成员”并挑选空闲编号，注册成功后自动跳转测量页
- **游客称重**：点击游客卡片，输入身高、年龄、性别，跳转测量页进行临时测量
- **测量**：站上体脂秤，等待数据自动出现，查看详细分析报告
- **历史记录**：点击用户卡片进入测量页，可查看历史表格；点击表格行可展示该次分析
- **导入导出**：点击齿轮 → 数据管理，可导出/导入 CSV，重置所有数据
- **编辑用户**：点击用户卡片左上角的铅笔图标，可修改用户信息或升级/降级用户类型
- **开发者面板**：按住 Shift 键点击标题打开

## 📊 数据来源与参考标准

### 体脂排名
本项目的“体脂排名”分析功能，参考了 **《第六次全国国民体质监测公报》** 发布的各年龄段、分性别的体脂率平均值及标准差数据。
- **数据来源**：国家体育总局  
- **统计方法**：基于上述公报提供的年龄段平均体脂率，结合正态分布模型，计算当前测量值在同龄、同性别群体中的百分位排名，以“优于 XX% 的同龄人”形式呈现。

> ⚠️ 该排名仅供参考，不能替代专业医学诊断。

### 基础代谢率校准
本应用提供了基于 **Mifflin-St Jeor 公式** 的基础代谢率校准值。该公式是国际公认的估计静息能量消耗的金标准。
- **公式来源**：Mifflin, St Jeor 等人于 1990 年提出，美国营养与饮食学会（AND）推荐。
- **男性公式**：`BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 + 5`
- **女性公式**：`BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 - 161`

> 本应用同时显示体脂秤原始基础代谢值和校准基础代谢值，用户可自行对比参考。

## 📂 项目结构
```
ryfit/
├── app.py                    # Flask 主程序，路由与 WebSocket 事件转发
├── config.py                 # 全局配置（蓝牙、数据库、超时、测量阈值等）
├── requirements.txt
├── models/                   # 数据访问层
│   ├── database.py           # SQLite 数据库初始化
│   ├── user_dao.py           # 用户 CRUD
│   ├── measurement_dao.py    # 测量记录 CRUD
│   └── settings_dao.py       # 全局设置存取
├── ble/                      # 蓝牙子系统（模块化，无事件总线）
│   ├── __init__.py           # 对外统一接口，注入 Socket.IO emitter
│   ├── constants.py          # 蓝牙状态、测量阶段与事件常量
│   ├── protocol.py           # 协议解析与指令构造（纯函数）
│   ├── core.py               # 蓝牙连接管理、心跳、空闲监控（纯通信）
│   ├── state_machine.py      # 蓝牙连接状态机
│   ├── session.py            # 测量会话（状态机、自动 C0、数据校验与存储）
│   ├── slot_manager.py       # 槽位查询、自动创建固定用户、孤立清理
│   ├── sync_manager.py       # 历史同步（重试、避让测量）
│   └── handlers.py           # 数据分发器
├── static/
│   ├── css/
│   │   ├── style.css         # Fluid Typography 全局样式
│   │   └── user.css          # Fluid Typography 测量页样式
│   ├── js/
│   │   ├── api.js            # REST API 封装
│   │   ├── modal.js          # 弹窗组件
│   │   ├── status.js         # 蓝牙连接指示器
│   │   ├── app.js            # 首页逻辑
│   │   └── user.js           # 测量页状态机（超时弹窗、自动重试引导）
│   └── socket.io.min.js      # Socket.IO 客户端
├── templates/
│   ├── base.html
│   ├── index.html
│   └── user.html
├── electron/                 # Electron 打包相关（可选）
└── README.md
```
